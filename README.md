# Hub of Olimpus — Video Streaming Interface (V27)

## Português

O **Hub of Olimpus** é uma interface de streaming de alta performance desenvolvida em HTML5, CSS3 e JavaScript puro. O projeto foca em uma experiência de usuário fluida e internacionalizada.

### 🚀 Funcionalidades
* **Detecção Automática de Idioma:** O sistema identifica o idioma do sistema operacional do usuário e traduz a interface automaticamente.
* **Scroll Infinito:** Carregamento dinâmico de conteúdo conforme a rolagem.
* **Interface Responsiva:** Design tático adaptável para Mobile e Desktop.
* **Modo Teatro:** Player integrado com sistema de sobreposição (overlay).

### 🛠️ Tecnologias
* HTML5, CSS3 (Variáveis nativas), JavaScript Vanilla.
* Integração com API JSON externa.

## English

**Hub of Olimpus** is a high-performance streaming interface built with HTML5, CSS3, and pure JavaScript. The project focuses on a fluid, internationalized user experience.

### 🚀 Key Features
* **Auto Language Detection:** The system identifies the user's OS language and translates the interface automatically.
* **Infinite Scroll:** Dynamic content loading as the user scrolls down.
* **Responsive Interface:** Tactical design adaptable for Mobile and Desktop.
* **Theater Mode:** Integrated player with a custom overlay system.

### 🛠️ Technologies
* HTML5, CSS3 (Native variables), Vanilla JavaScript.

## Русский

**Hub of Olimpus** — это высокопроизводительный интерфейс для стриминга, созданный на HTML5, CSS3 и чистом JavaScript. Проект ориентирован на плавный пользовательский опыт и международную локализацию.

### 🚀 Основные характеристики
* **Автоматическое определение языка:** Система определяет язык операционной системы пользователя и автоматически переводит интерфейс.
* **Бесконечная прокрутка:** Динамическая загрузка контента по мере прокрутки страницы.
* **Адаптивный интерфейс:** Тактический дизайн, подходящий для мобильных устройств и ПК.
* **Режим кинотеатра:** Встроенный плеер с системой наложения (overlay).

### 🛠️ Технологии
* HTML5, CSS3 (нативные переменные), Vanilla JavaScript.
* Интеграция с внешним JSON API.
